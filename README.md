## Что это такое

**A-hub для Android** — неофициальный мобильный порт A-hub: приложения для общения с ИИ, работы с текстом, файлами и задачами. Привычный интерфейс адаптирован под телефон и дополнен мобильными возможностями.

Приложение запускается самостоятельно: держать Windows-компьютер включённым не требуется. Для запросов к моделям нужны интернет, доступность сервиса A-hub и действующий ключ доступа. Доступные модели и функции генерации зависят от сервиса и вашего доступа.

Новости и информация об **оригинальном A-hub** — в [официальном Telegram-проекте AethelStore](https://t.me/AethelStore). Этот репозиторий посвящён Android-порту.

## Установка

1. Скачайте **[A-hub.apk из последнего релиза](https://github.com/MRMOXT/A-hub-ported/releases/latest/download/A-hub.apk)**.
2. Откройте файл на телефоне. Если Android попросит, разрешите установку для приложения, из которого открываете APK.
3. Запустите A-hub и введите действующий ключ доступа.

**Требования:** Android 7.0+, 64-битная ARM64-система. В APK также включена x86_64 для эмуляторов. 32-битные устройства не поддерживаются.

Обновление устанавливайте **поверх предыдущей версии**, чтобы сохранить данные. Удаление приложения удаляет его локальные данные.

> Телефон определяется как отдельное устройство. Если ключ привязан к Windows-компьютеру, обратитесь к администратору оригинального A-hub по поводу доступа с телефона.

## Как пользоваться

- **Скрепка** → камера, фото, файл или папка A-hub. Выбранное вложение появляется в сообщении перед отправкой.
- **Проекты** → создайте проект, задайте инструкции и начните чат либо добавьте существующий.
- **Навыки** → включите нужные инструкции. Новые и импортированные навыки сначала выключены; изучите текст перед включением.
- **☆ под ответом** → сохраните ответ в библиотеку.
- **Терминал Android** → введите команду и нажмите «Выполнить». Например: `pwd`, `ls -la`, `mkdir заметки`.
- **Настройки → О приложении** → проверьте обновления, источник загрузки и версию.

Навыки добавляют инструкции к следующим запросам модели. Они не устанавливают дополнительные программы и не расширяют права Android. Инструкции проекта применяются к его связанным чатам.

## Обновления и список изменений

Источник по умолчанию: **[MRMOXT/A-hub-ported · Releases](https://github.com/MRMOXT/A-hub-ported/releases)**.

Приложение проверяет обновления при запуске и планирует фоновую проверку раз в 6 часов. Android может отложить фоновую работу из-за энергосбережения или отсутствия сети. Для фоновых уведомлений разрешите их в настройках приложения.

Новый APK скачивается автоматически. Проверяются имя пакета и совпадение сертификата подписи; список изменений читается **из самого подписанного APK**. При наличии обновления приложение предлагает посмотреть изменения и установить его. Окончательное подтверждение установки выполняется в Android.

<details>
<summary><strong>Как опубликовать следующую версию</strong></summary>

1. Увеличьте `versionCode` и обновите `versionName` в `app/build.gradle`.
2. Обновите `app/src/main/assets/web/assets/changelog.md` перед сборкой.
3. Соберите релиз **тем же ключом подписи**.
4. Опубликуйте обычный GitHub Release, прикрепив APK с точным именем **A-hub.apk**. Черновики и предварительные релизы не используются.

Приватный ключ подписи и его пароли должны оставаться вне репозитория и релизов.

## Особенности Android

Файловые инструменты работают с папкой Documents приложения. Созданные документы можно экспортировать через системное окно сохранения. Терминал запускает `/system/bin/sh` с текущей папкой Documents, правами приложения, ограничением 30 секунд и выводом до 64 КБ. Команды, запрошенные моделью, требуют отдельного подтверждения даже при включённом авторазрешении файловых действий.

Root-права не предоставляются. Команды PowerShell и Windows EXE на Android не запускаются. Управление произвольными экранами других приложений не реализовано. Системные возможности зависят от установленных приложений и ограничений телефона.

Ключ сессии и файл проектов, навыков и библиотеки защищены AES-GCM через Android Keystore. Готовое APK не включает личные чаты, введённые ключи или учётную запись автора порта. Запросы к ИИ передают текст и выбранные вложения сервису A-hub.

## Разработчикам

Оболочка: **Java + Android WebView**. Локальная серверная часть: **Python 3.12 через [Chaquopy](https://chaquo.com/chaquopy/doc/current/android.html)**. Исходные веб-ресурсы и Python-модули восстановлены из Windows-сборки A-hub; это не полная реконструкция исходного Python-кода.

Для сборки нужны JDK 17, Android SDK Platform 35 и Python 3.12. Укажите SDK в local.properties. Для подписанного релиза нужны локальные signing.properties и ahub-release.jks; они исключены из Git.

```powershell
$env:JAVA_HOME='C:/Program Files/Java/jdk-17'
./gradlew.bat :app:assembleDebug
./gradlew.bat :app:assembleRelease :app:lintRelease
```

Скрипты в tools/ проверяют серверную часть, мобильную вёрстку и Android-интеграции. Интерфейс проверен на эмуляторе Android 15 в портретной и альбомной ориентациях. Проверки используют синтетические сообщения и не активируют учётную запись. Реальный вход и генерация требуют действующего ключа и отдельно не подтверждены этими тестами.
